# Tools — 实验与辅助脚本

| 路径 | 用途 |
|---|---|
| `手部监控器/` | 手部关键点实时监视，v1–v4（v4 含相对深度），`距离估算.py` |
| `参考长度计算器/` | 用已知参考长度估算手到摄像头的距离（V1–V1.2） |
| `双目视觉/` | 双目相机标定（`双目标定.py`）、识别、棋盘格测试 |
| `MultiTouchSimulator.py` | 多点触控模拟实验 |
| `hand——gesture.py` | 手势识别最初的实验脚本 |

这些脚本相互独立，依赖 `opencv-python`、`mediapipe`，按需运行。
