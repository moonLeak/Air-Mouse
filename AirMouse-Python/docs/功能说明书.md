# AirMouse（Python 版）功能说明书

用摄像头识别**单手**姿态，把手势变成鼠标操作：移动光标、左键点击 / 拖拽、右键点击、滚动。无需接触设备。基于 MediaPipe Hands，仅支持 macOS。

> 文中的"默认值"均取自代码（`airmouse/config.py` 等）。

---

## 1. 手势一览

抬起一只手，手掌朝向摄像头。

| 操作 | 手势 | 说明 |
|---|---|---|
| **移动光标** | 移动整只手 | 以手掌中心为指针，不是指尖 |
| **左键单击** | 拇指与食指**快速捏合再松开** | 捏合到松开不超过约 0.2 秒 |
| **左键拖拽** | 拇指与食指**捏住不放**，移动手，再松开 | 捏合超过约 0.2 秒即按下左键，松开后释放 |
| **右键单击** | 拇指与中指**快速捏合再松开** | 捏合到松开不超过约 0.25 秒 |
| **滚动** | 拇指与中指**捏住不放**，上下 / 左右移动手 | 捏住超过约 0.25 秒，或捏住后手移动较远（约 30 px），即进入滚动；松开后带惯性缓慢停止 |

**小技巧**
- 捏合用"指尖碰一下"的感觉，不必用力；动作要干脆，慢慢捏会被当成拖拽 / 滚动。
- 手离摄像头远近不影响捏合判定（距离已做归一化）。
- 手移动得很快时不会误松开拖拽（手速 > 200 px/s 时忽略松开信号）。
- 手放慢时光标会自动加强平滑，方便精确定位；快速移动时跟手更紧。

## 2. 使用

### 2.1 运行

环境安装见根目录 `README.md`。

| 方式 | 命令 | 说明 |
|---|---|---|
| 直接运行 | `python -m airmouse` | 打开摄像头窗口，开始控制 |
| 设置窗口 | `python -m airmouse.gui` | Tk 窗口，调参后点 **Start AirMouse** |
| 后台开关 | `python -m airmouse.toggle` | 运行中则停止，未运行则在后台启动；PID 与日志在 `~/.airmouse/` |
| 打包为 App | `packaging/build_mac.sh` | 生成 `.app` / `.dmg`，见 `packaging/安装说明.md` |

**退出**：在摄像头窗口按 `Esc`；终端里 `Ctrl+C`；GUI 里点 **Stop**。
> Python 版代码里有"握拳 3 秒退出"的识别模块（`gestures/special.py`），但**目前没有接入主程序**，握拳不会退出。

### 2.2 启动后的阶段：判定框（ROI）

程序会在摄像头画面里画一个**判定框**，手在框内的位置按比例映射到整个屏幕。

| 阶段 | 发生什么 |
|---|---|
| 空闲 | 画面里没有手 |
| 预览 | 手入画面，显示判定框和倒计时（默认 3 秒），框的大小随手掌宽度自适应 |
| 锁定 | 倒计时结束，框位置固定，开始控制 |
| 冻结 | 手短暂离开（默认 5 秒内）：框保留，回来可继续；超时则回到空闲重新判定 |

手移出判定框时，画面提示 `Re-center in N s`（默认 5 秒），这段时间内光标不动；开启"自动重新判定"时超时会重新生成判定框。

### 2.3 防误触：入场去抖

手刚进入画面时不会立刻操作，避免误点击：
- 需要手稳定一小段时间（默认 220 ms、连续 4 帧、抖动不超过 6 px）才开始响应；
- 响应之初光标速度从 25% 渐增到 100%（约 250 ms）；
- 判定前光标默认**冻结**（`AIRMOUSE_ENTRY_MODE=lowgain` 可改为低速移动）；
- 手短暂丢失（默认容忍 5 帧）不会被当成手离开。

### 2.4 手势判定原理

- **归一化距离**：拇指—食指 = `dist(4,8) / dist(3,7)`；拇指—中指 = `dist(4,12) / dist(3,11)`（MediaPipe 关键点编号），消除远近影响。
- **动态阈值**：取最近 5 帧的中位数为基线，低于 `基线 − 0.15` 算"捏下"，高于 `基线 + 0.15` 算"松开"。
- **光标位置**：手腕、拇指根部、食指根、无名指根、小指根等 6 个点加权平均，经卡尔曼滤波后映射到屏幕；手速低于 200 px/s 时加强平滑。
- **左右镜像**：默认水平镜像，使手往右移光标往右移。

### 2.5 设置窗口（`airmouse.gui`）

| 分组 | 项目 |
|---|---|
| Camera | 选择摄像头（可重新扫描）、画面缩放、水平 / 垂直镜像 |
| Monitor Overlay | 是否显示监视窗口、摄像头画面、曲线图、骨骼、指针锚点 |
| Pointer mapping | 判定框边缘内缩、触控板大小倍数、离开判定框后自动重新判定 |
| Gesture tuning | 捏合灵敏度（margin）、滚动速度、滚动平滑度 |
| 日志 | 运行输出，可一键复制、清空，出问题时发给开发者 |

设置保存在 `~/.airmouse_gui_settings.json`。

### 2.6 环境变量（常用）

不用 GUI 时，用环境变量调参，例如 `AIRMOUSE_CAMERA_INDEX=1 python -m airmouse`。

| 变量 | 默认 | 说明 |
|---|---|---|
| `AIRMOUSE_CAMERA_INDEX` | `0` | 摄像头编号；指定的打不开时会自动尝试 0–10 |
| `AIRMOUSE_FRAME_SCALE` | `0.5` | 画面缩放，越小越快但识别精度下降 |
| `AIRMOUSE_MIRROR_HORIZONTAL` / `_VERTICAL` | `true` / `false` | 镜像 |
| `AIRMOUSE_MONITOR_ENABLED` | `true` | 关闭则不显示任何调试窗口 |
| `AIRMOUSE_MONITOR_SHOW_GRAPH` / `_DRAW_SKELETON` | `false` | 曲线图 / 骨骼叠加 |
| `AIRMOUSE_MAX_HANDS` | `1` | 识别手数 |
| `AIRMOUSE_DETECTION_CONFIDENCE` / `_TRACKING_CONFIDENCE` | `0.5` / `0.3` | MediaPipe 置信度 |
| `AIRMOUSE_EXTEND_RATIO_X` / `_Y` | `2.5` | 手移动范围放大系数 |
| `AIRMOUSE_ROI_EDGE_PADDING` | `0.05` | 判定框边缘映射提前量（0–0.49），越大越容易碰到屏幕边缘 |
| `AIRMOUSE_ROI_COUNTDOWN_SECONDS` | `3` | 预览倒计时 |
| `AIRMOUSE_ROI_FREEZE_SECONDS` | `5` | 手离开后判定框保留时长 |
| `AIRMOUSE_ROI_EXIT_COUNTDOWN` | `5` | 手移出判定框后的重新判定倒计时 |
| `AIRMOUSE_ROI_AUTO_RESET` | `true` | 超时后是否自动重新判定 |
| `AIRMOUSE_TOUCHPAD_MULTIPLIER` | `1.8`（GUI 启动时为 `2.5`） | 判定框宽度 = 手掌宽度 × 此值，高宽比与屏幕一致 |
| `AIRMOUSE_PINCH_STABILITY` | `0.2` | 左键：点击与拖拽的时间分界（秒） |
| `AIRMOUSE_PINCH_MARGIN` / `AIRMOUSE_SCROLL_MARGIN` | `0.15` | 捏合灵敏度，越小越灵敏 |
| `AIRMOUSE_SCROLL_STABILITY` | `0.25` | 右键与滚动的时间分界（秒） |
| `AIRMOUSE_SCROLL_RADIUS` | `30` | 捏住后手移动超过此像素数即进入滚动 |
| `AIRMOUSE_SCROLL_SPEED_FACTOR` | `0.5` | 滚动速度 |
| `AIRMOUSE_SCROLL_SMOOTHNESS` / `_DECAY` | `0.8` / `0.9` | 滚动惯性：越大滑得越久 |
| `AIRMOUSE_ENTRY_DEBOUNCE_MS` / `_STABLE_FRAMES` / `_JITTER_PX` | `220` / `4` / `6` | 入场去抖 |
| `AIRMOUSE_ENTRY_SOFTSTART_MS` / `_GAIN0` | `250` / `0.25` | 起步渐进 |
| `AIRMOUSE_ENTRY_MODE` | `freeze` | `freeze` 或 `lowgain` |

## 3. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `not authorized to capture video` / 无法打开摄像头 | 未授权摄像头。**从哪个程序启动，就要给哪个程序授权**（终端、iTerm，或打包后的 App）。系统设置 → 隐私与安全性 → 摄像头 |
| 画面有、光标不动 | 未授予辅助功能权限，同位置勾选对应程序后重新运行 |
| 画面上下颠倒 / 左右反了 | 调整镜像设置（`AIRMOUSE_MIRROR_*` 或 GUI；大多数摄像头不需要垂直翻转） |
| 点击变成了拖拽 | 捏合太慢。动作要干脆，或调大 `AIRMOUSE_PINCH_STABILITY` |
| 经常误点击 | 调大 `AIRMOUSE_PINCH_MARGIN`；手入画面后先停一下再动作 |
| 光标抖动 | 放慢手速会自动加强平滑；或降低 `AIRMOUSE_FRAME_SCALE` 的同时保证光线充足 |
| 够不到屏幕边缘 | 调大 `AIRMOUSE_ROI_EDGE_PADDING` 或 `AIRMOUSE_EXTEND_RATIO_*` |
| 识别不稳 | 光线充足、背景简洁、手保持在画面内；只识别一只手 |
| 外接摄像头无法使用 | 换 `AIRMOUSE_CAMERA_INDEX`，或在 GUI 里选择；Continuity Camera 偶尔会报告已打开但读不到画面 |
| `No module named mediapipe` | Python 3.13 不被 mediapipe 支持，请用 Python 3.11 创建环境 |

---

## 4. 局限

- 只支持**一只手**。
- 需要摄像头正对手部、光线良好；强逆光会影响识别。
- 仅支持 macOS（依赖 pynput、pyobjc 与 AVFoundation 摄像头后端）。
